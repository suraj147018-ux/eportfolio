# Suraj - Physiotherapy Portfolio

Open `index.html` in a browser to view the portfolio.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. Your website will receive a GitHub Pages URL.

The profile photo is stored at `assets/profile.jpg`.
